# spritegen — 相棒(マスコット)の絵を作る

| ファイル | 役割 |
|---|---|
| `idle.py` | AIを使わず、1枚の絵を潰す/伸ばすだけで4コマを作る。姿勢は変わらない。**公開中のスプライトはこれで作られていない。実行すると11体が別のパルに置き換わるので注意** |
| `gen.py` | Gemini APIで4コマを描かせる。**画像生成は無料枠が0なので課金が要る**(2026-08-09 確認) |
| `fromsheet.py` | AIが描いた「4コマ1枚」を、使えるスプライトシートに整える |
| `sources/` | Geminiに描かせた元画像。ここから何度でも作り直せる |

## 通常

    python3 tools/spritegen/fromsheet.py tools/spritegen/sources/map.png --name map

## 1コマに2体いる絵(アイテム図鑑のウゴクゾー+ノロウゾー)

空白で切る自動分割だと**2体を別コマと数えてしまう**。格子指定と中心揃えを使う:

    python3 tools/spritegen/fromsheet.py tools/spritegen/sources/items.png --name items --grid 2x2 --center

## 公開中の11体を作り直すときのコマンド

絵ごとに設定が違う。**引数を省くと同じ絵にならない。**

    home breeding palbox combat base map boss tools ride   … 既定のまま
    dex                                                    … --white 225
    items                                                  … --grid 2x2 --center

`--white 225` は方眼紙の罫線(236,236,236)を消すため。ツッパニャンだけ必要。

## 一括で作り直さないこと(2026-08-10)

11体すべてを新しい処理で作り直して比較したところ、**良くなるものと悪くなるものが
両方出た**。現状のまま置いてあるのはそのため。

| | 結果 |
|---|---|
| パル図鑑 ツッパニャン | 罫線が消え、青い目が戻った → **差し替え済み** |
| ボス攻略 ジェッドラン | 頭上の白い線が消えた → 良くなるが未適用 |
| 道具系 アヌビス | 耳の青が戻った(57→126px) → 良くなるが未適用 |
| **出現マップ ペンタマ** | **白い腹が131→86pxまで削れた** → 悪化 |
| ライド レジェンディア | 白系 215→170px → やや悪化 |
| 他 | ほぼ変化なし |

原因は `saturation_weighted_resize`。彩度の高い画素を重く数えるので、
**狭くて鮮やかな特徴(目)は残るが、広くて彩度の低い面(白い腹)は隣の
鮮やかな色に負けて削れる。** 差し色の枠数を変えても直らないことは確認済み
(枠5→2でペンタマは104→86pxとむしろ悪化)。

作り直すなら**1体ずつ、前後を目で見比べてから**にすること。

## 絵を作り直したら

`shared/arcade.js` の `var V = "?v=..."` を上げること。上げないと古い絵を掴む。
