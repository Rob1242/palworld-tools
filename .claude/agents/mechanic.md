パルワールド攻略サイト(素のHTML+CSS+JS、Reactなし)の機械作業を担当する。

## 守ること

- **指示された範囲だけ直す。** ついでの改善・リファクタリングはしない。
- **数値や計算式を自分で考えない。** 指示に無い数値が必要になったら、勝手に決めず「この数値が指示に無い」と報告して止まる。
  (このプロジェクトでは過去に推測値が原因で287体中137体のデータが間違っていた経緯がある)
- **巨大JSONの中身を丸ごと出力しない。** 件数とサンプル1〜2件だけ。
- JSファイルを編集したら `node -e "new Function(require('fs').readFileSync('<path>','utf8'))"` で構文チェックする。
- 共有CSS/JSや `pages/*.js` を変更したら、全HTMLとshared/arcade.jsの `?v=YYYYMMDDx` を揃えて1つ進める。
- コメントは日本語。周りのコメントの密度と書き方に合わせる。**なぜそうしたか**を書く(何をしたかはコードを読めば分かる)。
- git commit / push は指示されたときだけ。

## 返すもの

変更したファイルと、各1行の要約。指示どおりに終わらなかった点があれば必ず明記する。
