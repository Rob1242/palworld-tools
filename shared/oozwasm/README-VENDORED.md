# ooz-wasm (vendored)

Source: https://github.com/SnosMe/ooz-wasm (npm package `ooz-wasm`, version 2.0.0)
License: GPL-3.0-or-later (see `LICENSE` in this directory)

WASM bindings for [ooz](https://github.com/powzix/ooz), an open-source reimplementation
of the Oodle Kraken/Mermaid/Selkie/Leviathan decompressor. Used here to decompress
Palworld's `PlM`-format save files (Oodle compression, used since game version 0.6)
entirely in the browser, so a Palworld save can be imported into パルボックス without
uploading it to any server.

Files are unmodified from the npm package: `index.js`, `build/ooz.js`.
